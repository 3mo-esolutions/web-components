## The whole library

```bash
npm install @3mo/del
```

```ts
import { Component, component, html } from '@3mo/del'
```

`@3mo/del` registers every element and re-exports the packages, together with `@a11d/lit` and the application framework `@a11d/lit-application`.

## One copy of each package

An element can be defined once per page, so an application loads exactly one copy of each package. The packages therefore list each other, `@a11d/lit` and `@material/web` as peer dependencies, and npm installs those next to your application by itself. When two packages need versions that cannot be one copy, `npm install` stops with an `ERESOLVE` error naming both; update the older one rather than passing `--legacy-peer-deps` or `--force`.

To stay on a version for a while, pin it in your own `package.json`:

```json
{
	"dependencies": {
		"@3mo/del": "x",
		"@3mo/field": "0.5.3"
	}
}
```

npm checks the pin against what the other packages require. If a newer package needs more, the install or `npm update` names it, and you pin that one too. An `overrides` entry forces a version without that check, for the cases where you accept the risk:

```json
{
	"overrides": {
		"@3mo/field": "0.5.3"
	}
}
```

A preview version is installed through an override as well, as ranges never match a prerelease on their own.

## Controllers

The pages under [Behaviors](?path=/docs/behaviors-selectability--overview) document Lit reactive controllers, which you import by name for your own elements:

```ts
import { SelectabilityController } from '@3mo/selectability'
```

## TypeScript

The packages ship as ES2022 modules with type declarations. Writing your own elements with the `@a11d/lit` decorators needs:

```json
{
	"compilerOptions": {
		"experimentalDecorators": true,
		"useDefineForClassFields": false
	}
}
```

## Fonts and icons

Components use the page's font. `--mo-font-family` starts with Roboto, which you load yourself:

```html
<link rel='stylesheet' href='https://fonts.googleapis.com/css2?family=Roboto:wght@400;500;700&display=swap'>

<style>
	:root {
		font-family: var(--mo-font-family);
		background-color: var(--mo-color-background);
		color: var(--mo-color-foreground);
	}
</style>
```

`mo-icon` loads the Material Icons font from Google Fonts when the first icon renders. Choose the variant before any icon is created; `@3mo/del` sets `sharp`.

```ts
import { Icon, IconVariant } from '@3mo/icon'

Icon.defaultVariant = IconVariant.Outlined
```

## Server-side rendering

Elements tagged `@ssr true` in their source render with Lit SSR. On the server, provide the icon font yourself.
