## Reading a component page

- **Header**: what the component is, its tag, version and status, and links to npm and the source.
- **Install** and **Import**: the two lines to copy.
- **Demo**: the component live, with controls to try its options.
- **Examples**: one idea each, explained in a line or two. **Show code** reveals the code.
- **API**: attributes, properties, events, slots, CSS custom properties and CSS parts.
- **Changelog**: every release of the package, at the end.

The toolbar switches every page:

- **Theme**: System, Light or Dark.
- **Language**: the language of every component; a right-to-left language also turns the page around.

Select a story in the sidebar to open it on its own: the **Actions** panel lists the events its elements fire.

## Status

A **Preview** badge marks a component whose API may still change. Everything without one is stable.
