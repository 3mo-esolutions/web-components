## Translate

```ts
import '@3mo/localization'   // makes t() global, as @3mo/del does

t('Save')
t('Hello ${name}', { name: 'Ada' })
t('Updated on ${date:Date}', { date: new Date() })
```

- The key is the text in the source language, which therefore needs no dictionary, plurals aside.
- A typed placeholder such as `${count:number}` or `${date:Date}` types its parameter. Numbers and dates are formatted for the language.
- `t()` returns a `LocalizedString` typed as `string`. It renders as text; wrap it in `String()` before comparing.

## Dictionaries

```ts
import { Localizer } from '@3mo/localization'

Localizer.dictionaries.add('de', {
	'Save': 'Speichern',
	'Hello ${name}': 'Hallo ${name}',
})

Localizer.dictionaries.add({
	de: { 'Cancel': 'Abbrechen' },
	fa: { 'Cancel': 'لغو' },
})
```

- The translation added last wins, so yours can replace the ones of the components.
- A missing translation falls back to the source language, then to the key, and logs a warning.

## Translations of the components

The components render the source language until you import the languages you support. `@3mo/del` gathers every package's translations of a language in one file:

```ts
import '@3mo/del'
import '@3mo/del/translations/de'
```

Without `@3mo/del`, import each package's file instead, such as `@3mo/data-grid/translations/de`. Import them before your own dictionaries, so that yours win.

## Plurals

```ts
Localizer.dictionaries.add('en', {
	'${count:pluralityNumber} new messages': [
		'${count} new message',
		'${count} new messages',
	],
})

t('${count:pluralityNumber} new messages', { count: 1 })   // "1 new message"
```

The array holds one form per plural category of the language, in the order `zero`, `one`, `two`, `few`, `many`, `other` of the categories it distinguishes, as `Intl.PluralRules` reports them.

## The current locale

```ts
Localizer.locales.current                     // an Intl.Locale, e.g. de-CH
Localizer.locales.current.language            // 'de'
Localizer.locales.current = 'fa'              // stored, and every Lit element re-renders
Localizer.locales.change.subscribe(locale => console.log(locale.baseName))
```

It comes from the `?lang=` URL parameter, the stored choice, the browser's language or `en`, in that order. A choice without a region adopts the one of the browser's matching language, so `de` on a Swiss browser is `de-CH`.

## Formatting

```ts
(1234.5).format()                          // "1234.5"         de: "1234,5"
(1234.5).formatAsCurrency('EUR')           // "€1,234.50"      de: "1.234,50 €"
(25).formatAsPercent()                     // "25%"            de: "25 %"
(12).formatAsUnit('kilometer')             // "12 km"
new Date(2026, 8, 26).formatAsDate()       // "Sep 26, 2026"   de: "26.09.2026"
['Anna', 'Ben', 'Cleo'].format()           // "Anna, Ben, and Cleo"
'1.234,5'.toNumber('de')                   // 1234.5
```

- Each uses the current language unless given one: `(1234.5).format('de')`, `(1234.5).formatAsCurrency('EUR', 'de')`.
- Dates also have `format()`, with the time, and `formatAsTime()`.

## Writing direction

`<body>` gets `lang` and `dir` for the current language, `dir='rtl'` for `fa`, `ar` or `he`, so the whole page flips with it. `DirectionsByLanguage.get()` returns the direction.
