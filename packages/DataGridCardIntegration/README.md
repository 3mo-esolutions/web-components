# Data Grid Card Integration

A utility for data grids inside cards that drops the card's side padding, so the grid spans its full width.

[![npm](https://img.shields.io/npm/v/@3mo/data-grid-card-integration?style=flat-square&color=0077c8)](https://www.npmjs.com/package/@3mo/data-grid-card-integration)

## Installation

```sh
npm install @3mo/data-grid-card-integration
```

```ts
import '@3mo/data-grid-card-integration'
```
