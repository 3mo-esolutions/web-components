# Date Time Value Constructor

A utility for API responses that revives ISO date strings as DateTime objects and serializes dates back to ISO.

[![npm](https://img.shields.io/npm/v/@3mo/date-time-value-constructor?style=flat-square&color=0077c8)](https://www.npmjs.com/package/@3mo/date-time-value-constructor)

## Installation

```sh
npm install @3mo/date-time-value-constructor
```

```ts
import { DateTimeValueConstructor } from '@3mo/date-time-value-constructor'
```

## API

### Exports

| Name | Kind | Description |
| --- | --- | --- |
| `DateTimeValueConstructor` | class | An API value constructor that revives the ISO date strings of API responses as `DateTime`s and sends dates as ISO strings. |
