# Font Importer

A utility for importing web font stylesheets into the document by URL, each only once.

[![npm](https://img.shields.io/npm/v/@3mo/font-importer?style=flat-square&color=0077c8)](https://www.npmjs.com/package/@3mo/font-importer) [![Documentation](https://img.shields.io/badge/docs-storybook-ff4785?style=flat-square&logo=storybook&logoColor=white)](https://3mo-esolutions.github.io/web-components/?path=/docs/utilities-font-importer--overview)

## Installation

```sh
npm install @3mo/font-importer
```

```ts
import { FontImporter } from '@3mo/font-importer'
```

## Examples

- [Default](https://3mo-esolutions.github.io/web-components/?path=/story/utilities-font-importer--default) — Importing a stylesheet URL makes its font available to the whole document.

### Exports

| Name | Kind | Description |
