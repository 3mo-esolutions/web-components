# Loading Button Dialog Adapter

A utility for dialog actions on loading buttons that shows the spinner while the action runs.

[![npm](https://img.shields.io/npm/v/@3mo/loading-button-dialog-adapter?style=flat-square&color=0077c8)](https://www.npmjs.com/package/@3mo/loading-button-dialog-adapter)

## Installation

```sh
npm install @3mo/loading-button-dialog-adapter
```

```ts
import '@3mo/loading-button-dialog-adapter'
```
