## Anchoring

`mo-popover-container` anchors the popover in its `popover` slot to the element beside it, which then opens it with a click or Enter. Elsewhere, set the popover's `anchor` to the element. It is positioned with CSS anchor positioning, and with Floating UI where the browser lacks it.

## Opening and closing

An `auto` popover closes on a click outside or Escape, while a `manual` one waits for `open`. Either way, `openChange` reports each change.

## Lazy popovers

The `popover()` directive declares a popover on its anchor. Given a `trigger` - `click`, `contextmenu` or `interest` for hover and focus - it renders the popover only once the anchor is first used, which keeps long lists of anchors cheap.
