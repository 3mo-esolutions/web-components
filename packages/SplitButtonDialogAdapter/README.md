# Split Button Dialog Adapter

A utility for dialog actions on split buttons that passes the executing state on to the main button.

[![npm](https://img.shields.io/npm/v/@3mo/split-button-dialog-adapter?style=flat-square&color=0077c8)](https://www.npmjs.com/package/@3mo/split-button-dialog-adapter)

## Installation

```sh
npm install @3mo/split-button-dialog-adapter
```

```ts
import '@3mo/split-button-dialog-adapter'
```
