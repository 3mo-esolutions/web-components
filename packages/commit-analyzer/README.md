# Commit Analyzer

A Node tool for parsing git log output into commits with conventional-commit types, breaking changes and trailers.

[![npm](https://img.shields.io/npm/v/@3mo/commit-analyzer?style=flat-square&color=0077c8)](https://www.npmjs.com/package/@3mo/commit-analyzer)

## Installation

```sh
npm install @3mo/commit-analyzer
```

```ts
import { Change, Commit } from '@3mo/commit-analyzer'
```

## API

### Exports

| Name | Kind | Description |
| --- | --- | --- |
| `Change` | class | Represents a change included in a commit. |
| `Commit` | class |  |
